# 레이아웃(페이지 레벨) 컴포넌트 규칙

> 대상: 화면 폭 전체를 차지하는 페이지 레벨 컴포넌트 — `Topbar`, `Footer`,
> `LnbNavigation`(사이드 네비) 등. 카드·버튼 같은 콘텐츠 컴포넌트에는 적용하지 않는다.

이 규칙은 CLAUDE.md의 토큰 규칙·4원칙 위에 얹히는 **레이아웃 세부 계약**이다.
Figma 프레임 크기를 컴포넌트 고정 크기로 착각해 반응형을 깨는 실수를 막는다.

## 1. 가로: 항상 `w-full`, 고정 폭 금지 (수평 바 기준)
- **적용 대상:** 화면 폭 전체를 차지하는 **수평 바**(`Topbar`, `Footer` 등). 수직 사이드 네비는 아래 예외를 따른다.
- 루트 요소는 `w-full`로 컨테이너 폭을 따른다.
- **Figma의 프레임 폭(예: 1920, 1440)은 프레임 크기일 뿐 컴포넌트 속성이 아니다.**
  `w-[1920px]`, `width: 1920px`, `max-w-[...]` 같은 고정/arbitrary 폭을 루트에 넣지 않는다.
- Figma auto layout의 **"fill container"(가로) = `w-full`**로 매핑한다.
  "hug contents" = 폭 지정 없음(내용 크기), "fixed" 가로는 페이지 레벨 컴포넌트에선 쓰지 않는다.

### 1-예외. 수직 사이드 네비게이션(`LnbNavigation` 등)은 축이 반대
수평 바와 달리 화면의 **세로 컬럼**을 차지하는 사이드 네비는 신축 축이 반대다 —
**가로 폭은 고정(컴포넌트 속성), 세로가 신축**한다. 따라서 규칙 1(가로 신축)이 아니라 아래를 따른다.
- **가로 폭 고정 허용:** 사이드 네비의 폭(예: 260)은 Figma 프레임 폭이 아니라 실제 컴포넌트 속성이므로 고정한다.
  단 `w-[260px]`(arbitrary)는 금지 — spacing 토큰으로 승격해 `w-260`처럼 쓴다(토큰이 없으면 `/sync-tokens`로 먼저 추가).
  raw px/arbitrary 금지는 그대로 유효(hook 차단).
- **세로 신축:** `h-full` + 내용이 넘치면 `overflow-y-auto`. Figma 프레임 높이(예: 1088)는 프레임 크기일 뿐이므로 무시한다.
- **하단 고정 영역:** 중간 영역을 `flex-1`로 밀어 하단 항목(예: Analytics)을 바닥에 고정한다(규칙 2의 자동 신축 원칙 동일 적용).
- 이 예외는 "고정 폭 금지"의 취지(프레임 폭을 컴포넌트 폭으로 착각한 반응형 파괴 방지)를 어기지 않는다 —
  사이드 네비의 폭은 착각이 아니라 실제 고정 속성이며, 값도 arbitrary가 아니라 토큰으로 표현하기 때문이다.

## 2. 내부 배치: 토큰 간격 + 자동 신축
- 그룹 간 양끝 배치는 `justify-between`으로, 늘어나야 하는 영역은 `flex-1`로 처리한다.
  픽셀 마진으로 밀어내지 않는다(반응형 유지).
- 요소 간 간격은 반드시 spacing 토큰 유틸리티(`gap-24`, `px-30` 등)만 사용한다.
  raw px/arbitrary 금지(CLAUDE.md 토큰 규칙과 동일, hook이 차단).

## 3. 세로: 높이만 Figma 스펙 고정
> 이 규칙은 **수평 바** 기준이다. 수직 사이드 네비는 세로가 신축하므로 규칙 1-예외를 따른다(높이 고정 안 함).
- 세로 높이는 Figma 스펙을 따른다(예: Footer 40px).
- 단, 높이도 raw px가 아니라 토큰으로 표현한다.
  기존 spacing 토큰이 없으면 `py-*` + 타이포 line-height 합성으로 만들거나,
  값이 반복되면 `/sync-tokens`로 토큰을 먼저 추가한다(직접 raw px 금지).

## 4. 검증(Evaluate)
- 페이지 레벨 컴포넌트 스토리는 `parameters.layout: "fullscreen"`로 둔다.
- **수평 바:** 대표 뷰포트(1920 / 1440 / 1024) 각각에서 좌/우 그룹의 **양끝 정렬이 유지**되는지
  스토리로 확인한다. 폭이 바뀌어도 가운데가 신축될 뿐 양끝은 고정이어야 한다.
- **수직 사이드 네비:** 폭 고정(`w-260` 등)이 유지되고, 컨테이너 높이가 바뀌어도 세로가 신축(`h-full`)하며
  하단 고정 항목이 바닥에 붙는지 확인한다(fullscreen + `h-screen` 래퍼 스토리).
