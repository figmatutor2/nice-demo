# 화면 설계서(디스크립션) 양식

> 출처: Figma "NHN 실습 디자인시스템" 기획문서(node 289-2654) 양식을 재사용 가능한 템플릿으로 등록.
> 디스크립션/화면설계서를 작성할 때는 이 양식을 그대로 따른다.

화면 설계서는 **두 블록**으로 구성된다.

1. **헤더 표** — 화면의 식별 정보(화면 / 화면 ID / 화면타입 / LOCATION / 화면구분).
2. **Description 표** — 화면의 동작을 번호 항목(`01`, `02`, …)으로 기술.

---

## 1. 헤더 표

| 항목 | 설명 | 예시 |
|------|------|------|
| **화면** | 화면 이름(사람이 읽는 명칭) | 비밀번호 재확인 |
| **화면 ID** | 시스템 식별자(팀 규칙에 따른 코드) | MY_010101 |
| **화면타입** | 구현 형태 | React |
| **LOCATION** | 사용자 도달 경로(`>` 로 단계 구분) | 클라우드 콘솔 > 비밀번호 재확인 |
| **화면구분** | 화면 단위 구분 | Page |

## 2. Description 표

- 각 행은 번호(`01`, `02`, …)와 내용 셀로 구성한다.
- 내용 셀은 **[구분] 제목**(예: `[Page] …`, `[확인] 버튼`)으로 시작하고,
  그 아래에 `1.`, `2.` 로 소분류를 나눈 뒤 `-` 불릿으로 상세를 적는다.
- 번호 항목은 보통 **화면(Page) 하나 + 조작 요소(버튼·필드 등)마다 하나**로 나눈다.

---

## 작성 규칙

1. **정적 구성은 디자인 링크에서 읽어 채운다.**
   화면에 보이는 정적 구성(제목·문구·필드 라벨·버튼 명칭·배치)은 추측하지 말고
   해당 화면의 Figma 디자인 링크에서 실제 값을 읽어 기입한다.

2. **요구사항에 없는 항목은 지어내지 말고 생략한다.**
   화면에 보이는 정적 구성은 디자인 링크에서 읽어 채우고, 요구사항에 없는 항목
   (출력 정보·저장 정보 등)은 지어내지 말고 생략한다. 빈 칸을 채우기 위해
   존재하지 않는 동작·데이터·API를 창작하지 않는다. 불확실하면 불확실하다고 남긴다.

3. **동작은 조건 → 결과로 적는다.**
   "무엇을 하면(클릭·불일치·성공 등) 무엇이 된다(전환·caution·이동 등)" 형태로,
   성공/실패 등 분기가 있으면 각각 명시한다.

4. **헤더 표의 5개 항목은 값이 있으면 모두 채운다.**
   값을 알 수 없는 항목은 비우되 임의 값으로 채우지 않는다.

5. **산출물 형태 — 최종 산출물은 스토리다.**
   디스크립션/화면설계서 요청의 최종 산출물은 `DescriptionGuide` 컴포넌트를 채운
   스토리다 — md 정리(중간 산출물) 후, 화면 슬롯(이미지 또는 페이지 컴포넌트) +
   지시번호 마커 + 우측 Description 테이블로 렌더한다.

---

## 산출물 형태 (DescriptionGuide)

이 양식(위 헤더 표 + Description 표)은 두 단계로 만든다.

1. **중간 산출물 — md 정리:** 이 문서 형식으로 헤더/Description 내용을 먼저 확정한다
   (예: `docs/descriptions/*.md`). 값 출처·판독 근거를 여기서 남긴다.
2. **최종 산출물 — DescriptionGuide 스토리:** 확정한 md 내용을
   `src/components/DescriptionGuide` 컴포넌트에 채워 Storybook 스토리로 렌더한다.
   구성은 다음 세 가지다.
   - **화면 슬롯:** 대상 화면(이미지 또는 페이지 컴포넌트).
   - **지시번호 마커:** 화면 위에 `01`, `02` … 번호를 절대 위치로 얹어 Description 항목과 연결.
   - **우측 Description 테이블:** 헤더 표 + 번호별 동작 설명.

---

## 예시 — 비밀번호 재확인 (MY_010101)

### 헤더 표

| 항목 | 값 |
|------|-----|
| 화면 | 비밀번호 재확인 |
| 화면 ID | MY_010101 |
| 화면타입 | React |
| LOCATION | 클라우드 콘솔 > 비밀번호 재확인 |
| 화면구분 | Page |

### Description 표

| # | 내용 |
|---|------|
| **01** | **[Page] 비밀번호 재확인**<br><br>**1. 노출 조건**<br>- 콘솔 우측 상단 계정(메일 주소) 클릭 > [회원 정보] 선택 시 NHN 클라우드 페이지로 전환되며 노출<br><br>**2. 검증**<br>- 비밀번호 불일치 시 입력 필드 caution 상태 + 오류 문구 노출 |
| **02** | **[확인] 버튼**<br><br>**1. 클릭 시**<br>- 성공: 재인증 유효시간 1시간 부여, 마이페이지로 이동<br>- 실패: 페이지 유지, 입력 필드 caution 상태로 전환 |
